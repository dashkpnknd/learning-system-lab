# Learning System Lab

Настольная обучающая система по информационным технологиям на Python и Tkinter. Включает учебные материалы, тесты и локальную базу SQLite.

Для запуска установите Pillow (`pip install Pillow`) и выполните `python main.py`. База `learning_system.db` создаётся локально и исключена из Git.
